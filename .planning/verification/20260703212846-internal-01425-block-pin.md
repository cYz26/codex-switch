# Internal 0.142.5 Block Pin

## Summary

`internal-rust-v0.142.5` is marked as a blocked default internal update target.
While it remains latest, internal switch/update checks keep or install pinned
fallback `0.142.4`. When latest advances to a successor release, auto-update
returns to the normal unpinned latest path.

The repair also makes shell CLI drift visible: `codex-switch status` reports
whether bare `codex` resolves to the codex-switch shim and prints
`eval "$(codex-switch shim-env)"` when PATH ordering is wrong.

## Evidence

- GitHub `SDGLBL/codex` releases still list `internal-rust-v0.142.5` as latest
  and `internal-rust-v0.142.4` as the previous release.
- Local rollback/reinstall evidence shows `/Users/cY/.local/bin/codex` at
  `codex-cli 0.142.4` passes both `--app-server-smoke` and
  `--responses-tool-smoke`.
- Before implementation, focused tests failed because `0.142.5` was treated as
  an ordinary latest release and status did not report PATH/shim alignment.
